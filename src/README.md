# Source modules

Edit these modules, then rebuild `Measey.js` with `python3 -X utf8 tools/build.py` from the repository root.

| Module | Purpose |
| --- | --- |
| `curve-math.js` | Bounded expression parser, Power curves and Bézier fitting. |
| `measey-host.js` | Cavalry selection, keyframes and easing operations. |
| `measey-ui.js` | Native panel, graph drawing and controls. |
| `measey-main.js` | Panel state, preferences, libraries and actions. |

Install the bundled `Measey.js`, rather than these individual modules.
